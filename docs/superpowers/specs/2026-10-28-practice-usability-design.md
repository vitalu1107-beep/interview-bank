# 练习可用性优化

用户已选择审计中的三项优化：手机快捷目录、题号精准定位、就地中文错误提示。

## 行为

- 手机练习时提供固定「目录 / 搜索」入口，复用现有目录和搜索框。浮层支持关闭、遮罩、Escape、键盘焦点约束；直接关闭恢复阅读位置，选择题目则进入目标位置。搜索后可直接查看结果。
- 完整题号忽略大小写和首尾空格，仅匹配该题；普通关键词和不完整题号继续全文搜索。保留收藏等筛选，Enter 定位匹配题卡。
- 草稿保存前在必填字段旁显示中文提示，保存区域显示摘要，并聚焦第一个错误。可选字段仍可留空；输入修正后清理过期提示。并发保存失败也在编辑处提示。

## 约束

保留 122 题、正式数据、草稿格式、存储键、现有导航返回、导入导出及部署方式。桌面保持现有侧栏。URL 历史恢复不在本次范围。

## 验证

先补有行为意义的回归测试，再实现；执行 npm run check。浏览器实际检查 1440/768/390/375 宽度、目录焦点与位置、搜索、错误修正、草稿、关联返回。提交新 PR，待用户审核。
