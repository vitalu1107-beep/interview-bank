# 进入练习与关联题返回

用户反馈：选择左侧分类后仍滚回欢迎页，题目被欢迎区挤到屏幕下方；从原题跳到关联追问后无法直接返回。

沿用原生页面与现有目录。在选择分类、小类、题目、继续练习、搜索或筛选时收起欢迎和概览区域，练习目录与内容从品牌栏下方开始；分类、小类与栏目入口直接定位首题，工具区可向上滚动查看。品牌入口可返回欢迎页。选择一级分类显示该类全部题目，二级分类继续缩小范围；不再出现“分类有题，但当前题数为零”的目录概览。

关联题链接保存当前来源、筛选、搜索、答案展开、草稿视图与点击链接的屏幕位置。目标题卡上方显示“返回 A10 原题”一类按钮，恢复来源上下文和阅读位置。允许多层关联跳转逐级返回；手动换分类、搜索或筛选时结束这一跳转链。记录只存在本次页面内存中，刷新仍加载正式答案，不新增或改变localStorage键。

采用页面内来源栈，因为现有链接未接入浏览器路由，改造全站history会扩大本次范围。直接保留一个来源会丢失多层跳转，故使用轻量内存栈。浏览器原生后退继续保留其原有行为，本次增加明确可见的返回入口。

未保存编辑仍阻止离开和重绘，包含返回首页、进入练习及返回原题。题库、导出与草稿保存结构不变；不增加依赖，不变更部署方式。先补充能复现问题的导航行为测试，再实现并检查桌面与375/390px手机。
